# DB Study

Repositório com meus estudos práticos sobre banco de dados, com exercícios de **SQL (MySQL/MariaDB)** e **NoSQL (MongoDB)**.

## Objetivo

Consolidar fundamentos de modelagem, criação de tabelas, relacionamento entre entidades, consultas e manipulação de dados em diferentes bancos.

## Estrutura do repositório

### `/mysql_mariadb`
Scripts SQL de aulas práticas, cobrindo:
- criação de banco e tabelas;
- inserção, atualização e remoção de dados;
- alterações de estrutura com `ALTER TABLE`;
- chaves primárias e estrangeiras;
- consultas com `JOIN`, agregações e filtros.

### `/nosql_mongodb`
Exemplos de estudos com MongoDB, incluindo:
- inserção de documentos;
- uso de coleções;
- consultas e exemplos de agregação no playground.

### `/copilot_excel/e-cards`
Projeto de estudo com scripts SQL para um cenário de cards (TCG):
- criação de tabelas de tipos, estágios, coleções e cartas;
- relacionamentos com chaves estrangeiras;
- carga inicial de dados (`seeds`) e consultas de validação.

## Observações

- Os arquivos foram organizados como material de estudo e prática.
- Os scripts podem evoluir conforme avanço dos estudos.
